# Introduction

The Terra RFC Book is a collection of casual documentation for [Terra](https://terrapkg.com).

Anyone can submit pull requests / RFCs to [this repository](https://github.com/terrapkg/rfcs).
You can write about current problems, suggestions, tutorials, examples, etc.
Anything Terra-related can go here.

The RFC site is available here: https://terrapkg.github.io/rfcs/
